# 🌾 Tarım Asistanı

## Açıklama
Tarım Asistanı, çiftçilerin tarlalarında ekim, sulama, hasat, aktivite takip edebileceği, aktivitelerini arayabileceği ve tarla planlaması yapabileceği bir tarla takip ve akademik yönetim uygulamasıdır.

## Kullanılan Teknolojiler

- React.js
- Node.js + Express.js
- MongoDB Atlas (Mongoose ODM)
- JWT + bcrypt
- Axios
- Vercel (Frontend)
- Render (Backend)

## Canlı Demo Linkleri

- Frontend: https://tarimasistani.vercel.app
- Backend: https://tarim-asistani-backend.onrender.com

## Kurulum Adımları

1. git clone
2. cd backend ; npm install
3. cd ../frontend ; npm install
4. backend/.env dosyasını oluştur ve MONGODB_URI, JWT_SECRET değerlerini gir
5. backend: npm run dev
6. frontend: npm start
